# 牛潞翔 · 视觉设计师作品集网站

静态站，原生 HTML / CSS / JS，**零依赖、零构建**。双击 `index.html` 即可预览，
也可以直接丢到 Vercel / Netlify / GitHub Pages 上。

中英双语，深色艺术馆风格（墨青底 + 朱砂红 + 青玉绿）。

## 一、怎么改内容（不用写代码）⭐

网站自带一个「点一下就能改」的编辑器。**你不需要打开任何代码文件。**

### 1. 双击 `编辑网站.bat`

会弹出一个黑色命令行窗口，然后自动打开浏览器，网址是 `http://127.0.0.1:4173`。

> 那个黑窗口**不要关**，它就是编辑器本体。用完了再关。
> 启动器会自动在 PATH、常见安装位置和 DSH 自带运行时里找 Node，
> 三条路都找不到才会提示。

### 2. 点右下角的「开始编辑」

进入编辑模式后，页面上所有**可以被改的地方**都会浮现虚线框，
右下角同时出现两个按钮：

- **完成编辑** —— 退出编辑模式（改过的东西不会丢）
- **撤销上一步** —— 后悔了就点它

### 3. 改图片：把鼠标移到图片上 → 点一下

鼠标悬停时会浮出小气泡提示「点击替换这张图」。点下去会打开电脑的选文件窗口，
选一张新图，**页面立刻就换好了**。

- 建议用 JPG / PNG / WebP，宽度 1600px 以上
- 图片会被自动保存到 `assets/img/uploads/` 文件夹，并自动改好引用

### 4. 改文字：把鼠标移到文字上 → 点一下

会弹出一个小面板，里面是**两个输入框**：

- 上面是**中文**，下面是**英文**

两个一起改，保存后中英两个版本同时更新——**不用改两次**。

### 5. 改完点「完成编辑」—— 网站会自己更新到线上 ⭐

**你不需要做任何别的操作。** 点「完成编辑」的那一下，改动就自动发布到线上了。

具体是这样：

| 什么时候会自动发布 | 说明 |
|---|---|
| 点「完成编辑」 | 推荐。通常你改完就会点它 |
| 停手约 20 秒 | 兜底。就算你忘了点，停手一会儿它也会自己发 |
| 点「发布上线」 | 想立刻发就点它，不用等 |
| 关窗口（按 Ctrl+C） | 如果还有没发的改动，会先发再退出 |

发布大约 **1 分钟**后在线上生效（GitHub 要重新构建一次）。
右下角会显示状态：`正在发布…` → `已发布 3ea6e20`。

> **改动在你点下去的瞬间就已经写进硬盘了**，不存在「忘了保存」。
> 就算当时断网发布失败，改动也还在本地，下次编辑会再试一次。

### 关于安全与后悔药

- 编辑器只在你自己的电脑上运行（只监听 `127.0.0.1`，同一局域网的其他电脑也访问不到）
- **每改一次，旧版本都会自动备份**到 `.editor-backup/` 文件夹，
  点「撤销上一步」可以一次退一步，连点可以一直往前退
- 编辑器的代码**不会写进你的网页文件**。也就是说，
  你上传到网上的那份是干干净净的、没有任何编辑器痕迹的正式网站

### 自动发布是怎么做到的（备查）

发布用的令牌存在 **`C:\Users\牛潞翔0.o\.portfolio-token`**，这个文件在网站文件夹**外面**，
所以它永远不会被发布上线，也不会出现在网站代码里。

发布逻辑在 `tools/deploy.mjs`。它**不是**用 `git push`——这台电脑到 `github.com:443`
的连接是不通的（实测超时），所以改成直接调 GitHub 的 REST API，
效果和一次 `git push` 完全一样。

它是**增量**的：先算出每个文件的 git blob 指纹跟线上对比，只上传真正变了的文件。
所以改一句话再发布，只传那一个文件，几秒钟就完成。手动发布：

```bash
node tools/deploy.mjs           # 正常发布
node tools/deploy.mjs --dry     # 只列出会变动哪些文件，不真的发
```

### 编辑器改不了什么

它只能改**已有的**图片和文字。如果想**增加**一个新项目、新增一个页面，
或者调整颜色、字体，那需要改代码——可以直接把需求告诉我。

## 二、本地预览（只看不改）

最简单的方式：直接双击 `index.html`。

但因为站点用了 `file://` 下可能受限的一些能力（`<dialog>` 模态、剪贴板复制、
Google Fonts 与 Lenis 的 CDN 加载），要看到与线上完全一致的效果，建议起一个本地服务：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

> 没有网络时站点依然可用：字体回退到系统字体，Lenis 平滑滚动会自动降级为原生滚动
> （`site.js` 里检测不到 `window.Lenis` 就直接返回）。所有交互都是渐进增强的，
> 即使 JS 完全失效，页面内容与导航依然可用。

## 五、换成真实图片（手工方式，备查）

用编辑器不需要看这一节。这里只说明原理，方便你理解文件是怎么变的。

**① 作品封面**（`works.html` 与首页精选作品）

```html
<img src="../assets/img/works/01-jinweier/cover.jpg" width="1600" height="1179" alt="项目名称" loading="lazy">
```

**② 详情页图版**（`.figure`）

```html

  <img src="../assets/img/works/01-jinweier/g1.jpg" alt="A05 标志释义" loading="lazy">
  <figcaption class="figcaption">01 — A05 标志释义</figcaption>

```

`.figure.span-2` 可以让某张图横跨两列（用于超长内页图）。
`.plate--tall` = 3:4、`.plate--wide` = 16:9、`.plate--square` = 1:1、
`.plate--banner` = 21:9，是空位占位块用的，现在只有关于页的个人照片还在用它。

## 六、改文案与双语（原理，备查）

所有文案都写成一对 span，**JS 只负责切 `<html data-lang>`，不动 DOM 文字**：

```html
<span data-lang="zh">中文文案</span>
<span data-lang="en">English copy</span>
```

`base.css` 里靠这两条规则控制显隐：

```css
html[data-lang="zh"] [data-lang="en"],
html[data-lang="en"] [data-lang="zh"] { display: none !important; }
```

所以**每条文案都要有 zh 和 en 两份**。语言选择存在 `localStorage` 的 `nlx-lang`，
`<head>` 里有一小段内联脚本提前读取，避免刷新时语言闪烁。

编辑器的文字面板就是自动帮你成对改这两份，所以你不用管这个规则。
改完记得跑一次自检（见下节），它会检查有没有漏写某一语言。

## 七、自检与截图

```bash
node tools/check.mjs          # 站点自检，退出码 0 = 通过
```

`check.mjs` 会检查：

1. 所有本地 `href` / `src` 是否指向真实存在的文件（跳过外链、`mailto:`、`tel:`、锚点）
2. 双语配对 —— 不仅数量一致，还会用栈式扫描确认**同一父元素下 zh 与 en 成对**
3. 每页是否恰好一处 `aria-current="page"`
4. 8 个详情页是否齐全，且「下一个项目」链路是否成环
5. `works.html` 卡片数、链接有效性、`data-cat` 与筛选按钮是否对应

```bash
node tools/shoot.mjs          # 截 index / works / about / contact
node tools/shoot.mjs --all    # 再加 8 个详情页
node tools/shoot.mjs --en     # 中英两套都截
```

产物在 `.shots/`：`<name>.png` 是整页图，`<name>@top.png` 是首屏视口图。
它用 Edge 的 DevTools Protocol 驱动真实渲染引擎，零 npm 依赖。
整页图会先把滚动揭示动画强制置为已进场，并把 `loading="lazy"` 的图片强制转为
立即加载 —— 否则视口外的内容会是空白。

```bash
node tools/make-resume.mjs --force   # 重新生成简历 PDF
```

## 八、部署

纯静态，把整个目录推上去即可（无需构建命令，无需环境变量）。

- **Vercel / Netlify**：直接拖拽整个文件夹，或连 Git 仓库，Build Command 留空、
  Output Directory 填 `.`（或仓库根目录）。
- **GitHub Pages**：推到仓库后在 Settings → Pages 里选分支根目录。

上线前建议先跑一遍 `node tools/check.mjs`。
注意 `assets/img/uploads/` 里如果有你用编辑器换上去的图，也要一起上传。

## 九、可以顺手调的地方

想改风格，基本只需要动 `assets/css/tokens.css`：

| 想改什么 | 改哪个令牌 |
|---|---|
| 主背景色 | `--c-bg`（当前 `#1E2A27` 墨青） |
| 卡片背景 | `--c-bg-raised`（当前 `#26332F`） |
| 点缀色 | `--c-accent`（当前 `#D25536` 朱砂红） |
| 次点缀 | `--c-jade`（当前 `#7FB8A1` 青玉绿） |
| 中文字体 | `--font-serif`（当前思源宋体） |
| 版心宽度 | `--maxw`（当前 1320px） |
| 段落留白 | `--section-y` |
| 动效快慢 | `--d-fast` / `--d-base` / `--d-reveal` |

字体由 Google Fonts 提供（Inter / Noto Serif SC / Space Mono）。如果要离线部署，
把字体文件下载到本地再改 `assets/css/tokens.css` 里的 `--font-*` 即可。
